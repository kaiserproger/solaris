# M98 - Operator/Admin MVP Docs And Tooling

**Status:** Planned. Quality label: `stabilization`.

## Agent Start Prompt

Read M77-M97, README, example config, ops/admin code, and the validation
ledger. Run preflight. Make the MVP operable.

## Goal

A fresh operator can run, diagnose, back up, restore, and understand the
scoped MVP without reading all milestone docs.

## Scope

- Admin guide: server jar, sidecar extraction, config, ports, ops,
  backups, restore, logs, metrics, autoscale profiles, drain/restart.
- Player guide: vanilla 26.1.2 setup and known non-goals.
- Config validation: unsafe public defaults, missing sidecar, bad world
  dir, port conflicts, backup dir, operator security.
- Commands/docs for `/save-all`, `/stop`, status/health, recovery.
- Dependency/operator audit: `Cargo.lock` changes justified, licenses
  reviewed, security-audit command/status recorded if available, zlib/LZ4
  dependencies documented.

## Acceptance

- Operator path works from docs alone or gaps are marked blocker.
- Unsafe configs warn or fail loudly.
- Known non-goals are visible to operators and players.
