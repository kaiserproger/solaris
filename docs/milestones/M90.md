# M90 - Concurrency Ownership Review II

**Status:** Planned. Quality label: `stabilization`.

## Agent Start Prompt

Read M77-M89, ADR 0003, M39, M42, M48-M52, and hot runtime code. Run
preflight. Review locks and blocking paths against the current feature
set.

## Goal

Remove obvious global lock and blocking-path risks before performance and
autoscale validation.

## Scope

- Inventory world/session/entity/storage/network locks and hot paths.
- Import unresolved M39.c-M39.h and M49.b-M49.e items as checklist rows.
- Audit M48 residual blocking paths: login-time playerdata load, startup
  sidecar/world prep, save/shutdown drain, slow clients, chunk storms,
  compression/network writes.
- Audit dirty eviction flush, Ctrl-C flush, generated chunk creation,
  relight, zlib/region IO, and compression under long locks.
- Treat the M77 generated-world live probe as a mandatory blocker input:
  Solaris correctly generated and streamed all 289 spawn chunks, but the
  debug-server run logged repeated `chunk_prepare` lock waits up to
  hundreds of ms, `save_all_flush` hold warnings, and 150-377ms runtime
  ticks while streaming a view-distance-8 generated world.
- Audit ownership for chunk prepare disk commit/snapshot, light compute,
  random ticks over ticketed chunks, dirty flush planning, and outbound
  chunk writes. Move or bound any blocking work before M91 measures final
  budgets.

## Acceptance

- Updated lock inventory and ownership table.
- No known network write, sleep, disk IO, or worldgen work happens under
  long world/session locks in scoped hot paths.
- Generated-world join/chunk streaming no longer produces unexplained
  `chunk_prepare` or `save_all_flush` budget warnings, or the remaining
  warnings are explicitly budgeted as non-green M91/M100 debt.
- Remaining locks have budgets and are tracked in M91/M96.
