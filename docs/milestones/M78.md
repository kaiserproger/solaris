# M78 - Real Client Automation MVP

**Status:** Planned. Quality label: `draft`.

## Agent Start Prompt

Read M77 and the validation ledger. Run preflight. Build the first
approved real-client automation path for vanilla 26.1.2. Protocol bots do
not satisfy this milestone.

## Goal

Make the manual/client evidence row automatable or at least reproducibly
prepared.

## Scope

- Design a local-only automation architecture: MCP server, wrapper, or
  equivalent harness.
- Launch or attach to a real vanilla/PrismLauncher client.
- Scenario v1: connect, wait for chunks, move, break/place one block,
  open/close one simple container, disconnect.
- Capture scenario file, client logs, server logs, screenshots or
  structured observations, commit id, toolchain, config, and failure
  notes.

## Acceptance

- Evidence can be reproduced from a scenario file or exact command list.
- Closeout labels the client gate `agent-run real-client`, `prepared
  owner-run`, or `blocked`.
- M78 evidence does not claim M100 coverage beyond the scenario actually
  observed.
