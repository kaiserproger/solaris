# M85 - Entity Ecosystem And Pathing Baseline

**Status:** Planned. Quality label: `draft`.

## Agent Start Prompt

Read M77-M84, M32-M33, M50, and entity harness tests. Run preflight.
Improve entities only where ledger-ranked blockers remain.

## Goal

Move entities from simple presence/combat toward a stable scoped survival
ecosystem.

## Scope

- Spawn/despawn caps and predicates for scoped passive/hostile mobs.
- Loaded-terrain bounded pathing: flat movement, step-up, simple detour,
  stuck recovery, no chunk generation from AI ticks.
- Passive behavior: wander and panic/flee if scoped.
- Hostile behavior: target acquire/forget, melee cadence/reach.
- Villagers/trading are implemented only if M77 made them M100 blockers;
  otherwise classify as non-goal/deferred.

## Acceptance

- Entity coverage table by type/family: spawn, sync, AI, damage,
  drops/XP, despawn, persistence, two-client evidence, accepted gaps.
- Harness and two-client evidence cover scoped behavior.
- AI budgets and lock behavior are measured or marked degraded.
