# M47 - Fluid and falling-block parity

**Status:** draft plan for owner review. Proposed branch:
`dev/M47-fluid-falling-parity`, cut from `main` after the preceding milestone tag.
**Owning crates:** `mc-world` for scheduled tick persistence, `mc-net` for runtime
block/fluid edits and packet dispatch, `mc-physics` for falling/fluid intent
primitives, `mc-test-harness` for vanilla and Solaris observations.

## Goal

Finish the M44-deferred block/fluid physics cases with capture-backed changes:
underwater breaking, water/lava replacement, source/flowing spread timing,
scheduled fluid ticks, and falling-block start behavior.

## Scope

- `water-lava-replacement` vanilla capture and Solaris comparison.
- Underwater block breaking replacement/drop behavior.
- Source/flowing water and lava spread for a small bounded fixture.
- Scheduled fluid tick persistence and timing in loaded chunks.
- `sand-gravel-fall-start` for sand, gravel, and anvil start/update behavior.

## Non-Goals

- Full vanilla fluid simulation.
- Redstone, pistons, bubble columns, cauldrons, boats, or pathfinding.
- Performance rewrites unless a scoped parity test regresses tick budgets.

## Strategy

1. Capture vanilla fluid/falling-block windows before changing runtime behavior.
2. Keep captures local and cite packet/world-state observations in docs/tests.
3. Add real play-path Solaris regressions for each fixed behavior.
4. Preserve M44 sugar-cane and item-drop behavior while changing fluid/block edits.

Acceptance:

### M47.d - Runtime Falling-Block Fixes

Acceptance:

- Sand, gravel, and anvil start behavior matches the captured oracle.

  implementation.

### M47.e - Closeout

Acceptance:

- Map every fixed case to a vanilla capture and Solaris regression.
- Defer broad fluid simulation explicitly if not captured.

## Risks

- Fluid spread can explode edit counts if budgets are not preserved.
- Falling blocks may need new entity packet/layout support; do not guess IDs or
  metadata.
- Underwater breaking touches drops, replacement states, and client acks in one
  path.
