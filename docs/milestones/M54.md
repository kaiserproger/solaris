# M54 - Projectile mechanics: bows and arrows

**Status:** foundation landed; arrow entity/deploy deferred. Branch: `dev/M54-projectile-arrows`, cut from `main` at `m53`.
**Owning crates:** `mc-net` for gameplay/bow mechanics, `mc-entity` for arrow entity lifecycle, `mc-physics` for projectile motion, `mc-test-harness` for bow/arrow integration tests.

## Goal

Implement bow-draw, arrow-fire, arrow projectile entity lifecycle, and arrow-on-hit
damage/pickup. This is the first projectile system in Solaris and should follow the
same entity/motion patterns already proven for mobs and dropped items.

## Scope

- Bow item recognition and use-item-released event handling.
- Arrow consumption from inventory (prefer offhand, then quickbar).
- Arrow entity spawn with velocity derived from draw power and look direction.
- Arrow projectile motion: gravity, air drag, block collision, entity hit.
- Arrow hit: damage application, knockback, arrow pickup eligibility.
- Integration test: shoot arrow, observe entity spawn, verify landed position.

## Non-Goals

- Crossbows, spectral arrows, tipped arrows, or fireworks.
- Arrow sticking in blocks visually (wire-level entity metadata only).
- Bow durability or enchanting.
- Projectile parity with vanilla bit-perfect physics.
- Multi-shot or piercing enchantments.

## Strategy

1. Add bow use-item-released handling in the play session dispatch.
2. Add arrow entity type, arrow component, and spawn path.
3. Add arrow projectile motion in mc-physics (gravity + drag + collision).
4. Add arrow-on-hit damage and pickup resolution.
5. Add integration test proving shoot → entity → motion → hit lifecycle.

## Sub-Milestones

### M54.a - Bow use and arrow consumption

Acceptance:

- Server recognizes bow item in held hand.
- On use-item-released, server reads draw duration and computes power.
- Server consumes one arrow from player inventory (offhand first).
- No arrow in inventory → bow does not fire.
- Unit tests for arrow consumption logic.

### M54.b - Arrow entity lifecycle

Acceptance:

- Arrow entity type registered in entity types.
- Arrow entity spawned at player eye position with velocity vector.
- Arrow applies gravity (9.8 m/s² downward) and air drag per tick.
- Arrow collides with solid blocks and stops.
- Arrow collides with entities and applies damage.
- Arrow can be picked up by players walking over it.
- Integration test validates full lifecycle.

### M54.c - Bow/arrow integration test

Acceptance:

- Harness-driven integration test: connect, give bow + arrows, draw, fire.
- Observe arrow entity spawn (AddEntity with arrow type).
- Observe arrow motion via position deltas.
- Observe arrow despawn on block hit or pickup after a few seconds.
- Non-ignored Solaris-only test, ignored vanilla-backed diff variant.

## Risks

- Arrow motion physics may diverge from vanilla; document approximations.
- Bow draw mechanics interact with client-side animation; server only validates.
- Entity collision with arrows may need separate hit registration to avoid
  double-damage on the same tick.
