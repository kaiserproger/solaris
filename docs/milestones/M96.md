# M96 - Multiplayer Survival Soak

**Status:** Planned. Quality label: `stabilization`.

## Agent Start Prompt

Read M94-M95, load scenarios, and the validation ledger. Run preflight.
Run combined multiplayer survival soaks.

## Goal

Exercise integrated gameplay under sustained multiplayer pressure.

## Scope

- Target 2-4 hour debug-server soak where feasible. Degraded fallback is
  at least a 30-minute replayable harness soak with the same action mix.
- Include real clients and/or harness clients, with at least two clients
  for visibility and contention.
- Actions: exploration, block edits, containers, crafting, mobs/combat,
  death/respawn, drops/XP, fluids/plants, save/autosave, disconnect,
  reconnect, slow reader.
- Required assertions: same-block concurrent edits, shared container RMW,
  shared item/XP pickup, disconnect during pending chunk work, bounded
  outbound queue, slow-reader behavior.

## Acceptance

- TPS/tick/memory/lock/queue/chunk latency and correctness outcomes are
  recorded.
- Property/replay corpus is updated; failing seeds produce manifests.
- Shortened/simulated soak says exactly what it failed to prove.

## Implementer 19/20 slice

Quality label: `stabilization`, validation degraded by missing local sidecars.

Added an ignored bounded harness replay scaffold in `load_scenarios.rs` for the
S2/O1-O2/Q3 target rows. The replay starts a debug in-memory server, connects
four active protocol clients plus one paused reader, drains chunks, exercises a
sequential same-block edit contention surrogate, drops a moved client before a
fresh reconnect, emits entity broadcasts, checks measured outbound pressure from
the paused reader, and asserts coarse chunk-pipeline and lock-hold budgets.

This is not a 30-minute or real-client soak. In this worktree the local
`data/vanilla/reports/{blocks,registries}.json`, `.analysis/server.jar`, and
`.analysis/test-world` artifacts are absent, so the sidecar-dependent load gates
are marked ignored and count as degraded unless run explicitly with local data;
an explicit run without sidecars fails with a degraded bootstrap message rather
than passing silently. The replay does not prove concurrent same-block races,
cancellation of already running chunk jobs after disconnect, TPS, long-duration
memory behavior, real-client behavior, shared container RMW, shared item/XP
pickup, or broad survival action coverage.
