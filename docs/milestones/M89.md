# M89 - Auth, Chat, Permissions, And Anti-Corruption MVP

**Status:** Draft implementation in progress. Quality label: `draft`.

## Agent Start Prompt

Read M77-M88, login/config/play packet handling, admin docs, and invalid
action tests. Run preflight. Harden public-facing behavior enough to
avoid corruption.

## Goal

Make normal and simple malicious clients safe for scoped MVP operation.

## Scope

- Decide online-mode scope: implement encryption/session auth or document
  offline-only as private/local and non-release-ready for public use.
- Duplicate-name/profile handling, whitelist, banlist, ops persistence,
  permission levels, public bind warnings.
- Chat/command policy: basic chat if scoped, or commands-only with safe
  ignores/rejections.
- Movement, reach, container, malformed packet, and resource-pack status
  sanity checks.

## Acceptance

- Invalid actions cannot duplicate items, corrupt containers, or bypass
  obvious reach/mode constraints in scoped paths.
- Local-dev OP defaults are disabled or loudly unsafe outside dev;
  ops/whitelist/banlist have restart tests.
- Security claims remain scoped; no full anti-cheat claim.

## Implementer 12/20 Slice

Quality label: `draft`.

Landed a bounded auth/admin admission slice:

- Solaris remains offline-mode only for M89. `online_mode = true` is rejected
  at login with `LoginDisconnect`; encryption/session-server auth is not
  implemented.
- Login access policy supports fail-closed whitelist and ban checks by player
  name or offline UUID before `SetCompression`, `LoginSuccess`, Configuration,
  or Play.
- Duplicate profile/name admission is still enforced at Play session
  registration and disconnects before registering the second session.
- Omitted `[admin]` no longer grants OP to every player. Local-dev OP is now
  explicit opt-in through `allow_local_dev_operators = true`.
- Offline public binds log a warning that the mode is private/local and not
  production-security-ready.

Evidence:

- `cargo test -p mc-net login::tests::access_rejection --lib` proves the
  access policy fails closed for unsupported online-mode, whitelist miss, and
  ban-over-whitelist precedence without constructing accepted data by default.
- `cargo test -p mc-server --test login` proves a real socket login rejection
  sends `LoginDisconnect` before compression and does not enter later states.
- `cargo test -p mc-server --lib` proves config parsing defaults and explicit
  auth/admin policy translation.

Known gaps:

- No Mojang online-mode encryption/session authentication.
- No persisted `ops.json`, `whitelist.json`, or `banned-players.json`; policy
  is TOML-configured only in this slice.
- No chat signing, chat moderation, or public chat policy beyond existing
  command gating.
- No new movement/reach/container malformed-action checks in this slice.
- Public bind behavior is warning-only; it does not make offline-mode safe for
  public servers.
