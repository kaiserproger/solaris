# M72 - Plants and farming parity

**Status:** Planned locally. Branch: `dev/M72-plants-farming-parity`, stacked
after local M71.
**Owning crates:** primarily `mc-net` and `mc-test-harness`, with docs updates to
the replacement-readiness plant scope.

## Goal

Tighten the existing plants/farming claim by turning unit-only deterministic
plant behavior into harness-covered behavior, then address small support/lifecycle
parity gaps that can be implemented through the existing plant policy layer.

M72 intentionally preserves Solaris' deterministic local plant semantics unless a
slice explicitly calls out a behavior change. Vanilla-exact RNG, full loot-table
execution, particles/sounds/statistics/game events, and large feature placement
remain future work.

## Priority Backlog

### M72.a - Deterministic Crop Harvest Harness Coverage

Move the remaining common deterministic crop harvest paths from unit-only
confidence to real survival wire coverage.

Scope:

- Add a stable harness that breaks mature carrots, potatoes, beetroots, and
  nether wart placed into an in-memory generated world.
- Assert the target block updates to air and that the expected deterministic drops
  appear through real item entity metadata or inventory pickup packets.
- Reuse existing wheat-harvest helper patterns rather than inventing new test
  infrastructure.
- Keep deterministic yields unchanged.

Non-goals:

- Vanilla RNG/fortune/loot-table parity.
- Poisonous potato chance.
- Exact break timing beyond the existing harness destroy flow.

### M72.b - Stem And Cocoa Harness Coverage

Cover the unit-only visible plant lifecycle paths that are most likely to desync a
vanilla client in ordinary survival play.

Scope:

- Add harness coverage for mature melon or pumpkin stem fruit placement and
  attached-stem conversion through a real bonemeal or random-tick-triggered edit
  if stable.
- Add harness coverage for cocoa bean placement or cocoa harvest if stable and
  cheap.
- Preserve deterministic fruit direction and cocoa yield rules unless this slice
  explicitly captures and changes them.

Non-goals:

- Vanilla random fruit-position selection.
- Exact cocoa shape/support/loot RNG.

### M72.c - Vertical Plant Growth Harness Coverage

Turn the current sugar cane/cactus/bamboo random-tick behavior into at least one
stable harness assertion.

Scope:

- Prefer one deterministic harness that drives the configured random-tick path on
  a seeded world and observes visible growth for a supported vertical plant.
- If random-tick timing is too noisy, add focused coverage around the real policy
  helper and record why harness coverage stayed out of scope.
- Preserve the current local height-three cap.

Non-goals:

- Vanilla age-counter timing, cactus side-neighbor survivability, sugar-cane water
  adjacency, bamboo stage/leaf transitions, or bonemeal behavior unless a narrow
  tested fix is clearly needed.

### M72.d - Support Semantics Audit

Document or tighten the smallest high-value support rules after the coverage
slices land.

Scope:

- Compare the current plant policy helpers against the readiness exclusions and
  record the exact local semantics per plant family.
- Fix obvious support mistakes only when the change is small, deterministic, and
  covered.
- Update `docs/REPLACEMENT_READINESS.md` so harness-covered paths are no longer
  described as unit-only.

Non-goals:

- Replacing the deterministic plant policy with vanilla feature placement or full
  block-survivability logic.

### M72.z - Closeout

Record what plant behavior is now harness-covered, what remained intentionally
deterministic, and what should move to the later loot/drop milestone.

Scope:

- Run focused plant harness/unit tests after each slice.
- Run the full workspace baseline before closing the milestone.
- Keep the manual PrismLauncher gate owner-run unless explicitly requested.
