**Status:** Planned. Branch: `dev/M65-bamboo-growth`, stacked after local M64.

for readiness and closeout.

## Goal

Allow existing bamboo columns to grow upward through the random-tick path.

## Scope

- Reuse the existing vertical-plant random-tick edit path.
- Grow supported clear bamboo columns by one block above the contiguous top.
- Keep existing support-break cascade behavior intact.

## Non-Goals

- Bamboo sapling placement or conversion parity.
- Exact vanilla age/stage/leaf-size state transitions.
- Exact vanilla height caps, light checks, RNG timing, bonemeal, particles,
  sounds, statistics, or game events.
- Timing-dependent wire harness coverage for random ticks.

## Validation
