# M100 Validation Ledger

**Status:** M77 frozen denominator. Quality label: `stabilization`.

This is the canonical scope and evidence ledger for the M100 core MVP. It
tracks client-observable vanilla 26.1.2 overworld-survival mechanics and
the non-gameplay evidence gates needed to claim replacement readiness.

Rows marked in scope are the M100 coverage denominator. Later removals
require owner approval and must remain visible in the denominator appendix.
Rows with only unit tests, Solaris-only harness tests, or implementation
existence do not count toward the 80% coverage numerator until they also
have linked vanilla oracle or real-client evidence.

## Status Vocabulary

| Status | Meaning |
|---|---|
| `ready` | Normal-path runtime tests plus linked vanilla oracle or real-client evidence exist for this exact row. |
| `partial` | Usable implementation and some tests/evidence exist, but the row is narrower than vanilla or lacks required oracle/client evidence. |
| `draft debt` | Implementation or scaffolding exists, but evidence is too thin for stabilization claims. |
| `accepted divergence` | Solaris intentionally differs from vanilla for the scoped MVP. Excluded from the coverage numerator, but visible to operators. |
| `non-goal` | Outside the scoped M100 MVP unless the owner changes scope. |
| `blocked` | A known failed/missing required gate prevents this row from counting. |
| `unknown` | Not enough current evidence to classify beyond future target work. |
