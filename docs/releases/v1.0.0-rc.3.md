# Solaris 1.0 "Pauline" RC3

Release candidate 3 of Solaris 1.0: RC2 plus one server fix so that
**NeoForge** players with Solaris Loader can join. Target is unchanged:
Minecraft Java Edition **26.3** (protocol 777); 26.1.2 (775) clients can still
join. See the [RC2 notes](v1.0.0-rc.2.md) for everything else in this
candidate.

**Upgrading from RC2:** replace the binary. Content cache and worlds stay as
they are. Upgrading from RC1 needs the two RC2 steps (`content import` and
`world upgrade-worldgen`).

## Server

- During configuration the server now declares its Loader channels
  (`minecraft:register`: `solaris:loader/hello`, `request`, `ack`,
  `view_action`). NeoForge sends a mod payload only on a channel the server
  declared, so on RC2 a NeoForge Loader client could not answer the Loader
  probe. Vanilla, Fabric, Forge and native clients ignore the declaration.

## Matching releases

- Solaris Loader **v1.0.0-rc.2** for Minecraft 26.3 (Fabric, NeoForge, Forge).
  Its NeoForge adapter needs this server or newer.
- Native client **v1.0.0-rc.3** (unchanged).

## Validation

- `mc-edge` configuration tests, including a test that failed on RC2: the
  server must declare `hello`, `request`, `ack` and `view_action` before the
  probe.
- Real-client `loader-live` (`loader-v2-settlements-smoke`) with this server
  passes on Fabric, NeoForge and Forge; the native client's `title-connect`
  passes.
- Everything else is as validated for RC2.
