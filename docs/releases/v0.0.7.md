# Solaris v0.0.7

Preliminary release for Minecraft Java Edition **26.1.2**. Maturity remains
**draft**: the release fixes common survival interactions, but graphical
real-client acceptance has not yet been recorded.

## Changelog since v0.0.6

### Mob interaction

- Adult cows, sheep, and chickens follow a nearby player holding their matching
  food in the selected hotbar slot or offhand. They resume wandering when no
  valid food holder remains.
- Skeleton bow attacks require a clear loaded path to their target. An opaque
  or unloaded cell prevents drawing and cancels a draw that loses sight.
- Copper tool recipes, breeding of cows/sheep/chickens, and player-to-mob
  pushing are included in this release.

### Containers

- Chest and double-chest lids now publish vanilla `minecraft:block_event`
  updates: the first viewer opens each lid and the last viewer closes it.
  Nearby players receive the animation independently of container UI state.

### First startup content

- A server with no existing Solaris content cache now resolves the configured
  Mojang artifacts automatically on first startup and reuses the validated
  local cache on later starts. Mojang bytes remain local operator data and are
  not redistributed in the source repository or release archive.

## Upgrade notes

Back up the world and configuration before upgrading. Existing configuration
files are not rewritten. The first launch that has no validated content cache
requires network access to obtain the configured Mojang artifact; later starts
reuse that cache.

## Validation boundary and known gaps

- Focused Rust coverage validates food temptation, skeleton sight rejection,
  chest block-event delivery, packet layout, automatic content import, durable
  settlement commits, and component startup.
- The canonical `correctness` gate passed: formatter, code-health, strict
  workspace Clippy, and all workspace targets.
- Installer, harness wiring, and release-binary build profiles passed locally.
- Graphical real-client, oracle, and performance gates are **not run** for this
  release; this release therefore remains **draft**.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/kaiserproger/solaris/v0.0.7/install.sh | \
  SOLARIS_VERSION="v0.0.7" bash
```

Linux x86_64 and AArch64 archives contain the server, starter configuration,
README, changelog, version marker, and licenses. Pin `v0.0.7`: GitHub's
`latest` alias does not select a prerelease.
