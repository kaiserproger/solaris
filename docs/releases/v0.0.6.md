# Solaris v0.0.6

Preliminary release for Minecraft Java Edition **26.1.2**. Maturity remains
**draft**: accumulated gameplay fixes, worldgen foundations and test-repair
sweep, not a claim of production readiness or completed graphical acceptance.
Villages (settlement behavior, villager/golem defense) are explicitly deferred
to the next slice.

## Changelog since v0.0.5

### Light and fluids

- Chest-family opacity now follows the waterlogged state (0 dry / 1 wet),
  matching the local 26.1.2 block-light report; the old conservative fallback
  made every chest fully opaque.
- Ender chests emit light level 7 on all states, matching the vanilla report.
- Flowing water displaces ground-support plants and columns with survival loot
  drops (upper double halves yield nothing; seagrass coexists). Lava keeps
  stop-at-plant: no vanilla evidence for lava-vs-plant displacement.

### Worldgen foundations (generation-only)

- Nether generator foundation: bedrock floor, fbm height field, lava sea,
  netherrack body, bedrock ceiling cap, single `nether_wastes` biome.
- End generator foundation (same single-biome pattern).
- Structure chest loot rolls at paste time from real vanilla tables
  (`simple_dungeon`, `village_toolsmith`) with a deterministic seed and fixed
  fallback contents; startup wires the catalog with warn-and-fixed fallback.
- No server wiring, portals, travel or multi-biome regions yet.

### Test-repair sweep (no gameplay change)

- Removed the dead `StructureSetFacts::placement_type` field (no consumer).
- Backfilled `stew_effects` into stale test constructors left by the food
  slice; added the 4MiB-thread pattern to one heavy pickup integration test.
- Aligned stale zombie fixtures to the HEAD 2.3 pursuit speed.
- Updated PVP and entity-killed wire expectations from the obsolete hurt
  entity event 2 to the 26.1.2 `ClientboundDamageEvent` the server emits.
- Rewrote the flaky short-grass seed wire test into a deterministic
  break-transaction check; the 1/8 seed probability stays covered by the
  fixed-seed corpus in `mc-data/tests/plant_loot.rs`.

## Upgrade notes

Back up the world and configuration before upgrading. Existing configuration
files are not rewritten. This release introduces no world-contract migration
beyond the alpha-3-to-alpha-4 boundary documented in v0.0.5.

## Validation boundary and known gaps

- Focused gates green at close: `mc-data` 261, `mc-worldgen` 137,
  `mc-entity` 635, `mc-server` 76, `mc-net` 2085, `block_edit` 36 passed
  with 70 ignored; formatter and code-health pass.
- Full workspace L2 is red on exactly one test:
  `village_defense_spawns_golem_and_attacks_hostile_over_tcp` (golem spawns,
  no attack within 20s; fails isolated too; unrelated to this release's
  files). Villages are the next slice.
- The ignored `mob_presence` zombie helper still expects the obsolete hurt
  event; same one-line follow-up, unverifiable without local sidecars.
- Graphical owner acceptance, oracle recapture and performance comparisons
  are **not run** for these changes.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/kaiserproger/solaris/v0.0.6/install.sh | \
  SOLARIS_VERSION="v0.0.6" bash
```

Linux x86_64 and AArch64 archives contain the server, starter configuration,
README, changelog, version marker and licenses. Pin `v0.0.6`: GitHub's `latest`
alias does not select a prerelease.
