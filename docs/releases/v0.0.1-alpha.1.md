# Solaris v0.0.1-alpha.1

Solaris is now available as a **public alpha** for Minecraft Java Edition 26.1.2.

This release is for testing, development servers, plugin experiments, and bounded multiplayer sessions. It is not a production-safe drop-in replacement for vanilla, Paper, Fabric, Forge, or an existing server fleet.

## What is usable

- Vanilla 26.1.2 login, chunk streaming, movement, block interaction, inventory, crafting, containers, persistence, respawn, common combat, passive/hostile mobs, merchant trading, and villager gossip.
- Server-owned Lua plugins with bounded configuration, storage, menus, inventory transactions, zones, timers, teleports, events, and example economy/claims/colony plugins.
- Optional Fabric and NeoForge client extension path for verified custom content.
- Linux x86_64 and AArch64 server archives with SHA-256 checksums and a hardened installer.

## Important alpha limits

- Solaris-owned persistence schemas, Lua APIs, and client-extension contracts may change without migration between alpha releases.
- Full vanilla parity is not claimed. Species-specific mob attacks, zombie-villager curing, Hero of the Village pricing, village population/defence, rare redstone/vehicle behavior, and broader performance envelopes remain incomplete.
- Prebuilt binaries are Linux-only. Windows and macOS builds are not published.
- The server targets exactly Minecraft Java Edition 26.1.2.
- Public internet deployment requires online mode, safe operator settings, and review of every `operator_warnings` entry from `solaris --check`.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/kaiserproger/solaris/main/install.sh | \
  SOLARIS_VERSION="v0.0.1-alpha.1" bash
```

Download the pinned starter config, review its local-only defaults, validate it, and then start the server:

```sh
curl -fsSLo server.toml \
  https://raw.githubusercontent.com/kaiserproger/solaris/v0.0.1-alpha.1/example.toml
solaris --check --config server.toml
solaris --config server.toml
```

A fresh missing world-directory warning is expected and `serve` will create it. The release archive contains `README.md`, `example.toml`, both licenses, a `VERSION` file, and the server binary.

## Reporting bugs

Include the Solaris version, Minecraft client version, operating system/architecture, config with secrets removed, relevant logs, and the smallest reproducible sequence. Do not report missing full replacement parity as a single bug; report one concrete client-visible failure at a time.
