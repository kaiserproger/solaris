# Archived checkpoint log

Чекпоинт-история Solaris, вынесенная из `docs/MEMORY.md`, чтобы живой курсор оставался
маленьким. Файлы нарезаны по **непрерывным** участкам исходного журнала (в порядке, в котором
они там лежали), поэтому повествование каждого чекпоинта не разъезжается по файлам.

**Это не стартовый контекст** (`AGENTS.md`): состояние проекта читается в
[`../MEMORY.md`](../MEMORY.md), сюда заходят за историей конкретной эпохи или за провенансом
решения.

| Часть | О чём |
| --- | --- |
| [log-01-villages-and-content-source.md](log-01-villages-and-content-source.md) | Ранняя разведка деревень, границы фич, источник ванильного контента (кэш + импортёр). |
| [log-02-settlement-c1-and-handover.md](log-02-settlement-c1-and-handover.md) | Профили поселений, закрытие ядра, путь записи склада (C1), снапшот передачи. |
| [log-03-gameplay-and-loader.md](log-03-gameplay-and-loader.md) | Постройки в рельефе, мобы и блуждание, связка плагин↔C4, бой C4, cutover Loader wire. |
| [log-04-releases-and-handoff-fixes.md](log-04-releases-and-handoff-fixes.md) | Релизы v0.0.6, починка тестов, серия handoff-issue (сундуки, вёдра, рыба, двойной сундук). |
| [log-05-performance-and-worldgen.md](log-05-performance-and-worldgen.md) | Проверенные оптимизации и верификация мира (реки, биомы, берега, свет). |
| [log-06-checkpoints-09-12-to-09-14.md](log-06-checkpoints-09-12-to-09-14.md) | Чекпоинты 09-12…09-14: tab-list, реки, деревни+редстоун, сигналы shutdown, feature executor A1. |
| [log-07-village-generation.md](log-07-village-generation.md) | Feature executor A2 (деревья), активация ванильной генерации деревень, village solver + decor lane. |
| [log-08-audit-closeout-and-inhabitants.md](log-08-audit-closeout-and-inhabitants.md) | Закрытие аудита ядра и жители деревень из маркеров частей (закрытый чекпоинт 09-15). |

Каждая часть начинается со списка своих секций — по нему ищется нужный чекпоинт без чтения
файла целиком.

Ссылки внутри частей относительны `docs/memory/`; при переносе текста из `docs/` они
переписаны на `../<файл>` (проверено скриптом, битых нет).

Правило пополнения: новый чекпоинт пишется в `../MEMORY.md` (живой курсор); когда он перестаёт
быть текущим, он переезжает сюда — в конец подходящей по времени части или в новую часть, без
переписывания текста.
